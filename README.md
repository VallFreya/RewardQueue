# Очередь наград (Reward Queue)

Плагин для OBS Studio (Windows) для стримов на Twitch. Собирает заказы наград за баллы канала Twitch в одну очередь: в доке OBS видно, что и кому нужно сделать, а зрители видят тот же список на трансляции. Нажали «Выполнено» или «Убрать» в доке, и запись пропала с трансляции.

> Проект в разработке, готовой версии пока нет.

## Что будет уметь

- Док в OBS с очередью выбранных наград: ник, сообщение зрителя, кнопки «Выполнено» и «Убрать», ручное добавление.
- Источник «Браузер» для трансляции с тем же списком.
- Вход в Twitch по коду, без пароля и без секретов в плагине.
- Горячая клавиша «Выполнено для первой награды».
- Очередь сохраняется на диск и восстанавливается после перезапуска OBS.
